# 手工教学验收

这些场景是待执行的验收规格，不是自动测试、真实学习记录或学习效果研究。
各行使用独立的临时聊天上下文；不要将人工夹具作为真实学习档案。案例内的多步操作按顺序执行。
时间均为构造的 UTC 时间。规则依据[状态规范](../references/state-and-review.md)和[课程约定](../references/lesson-quality.md)。

## 执行与报告

- 在宿主中显式调用 skill，提供指定初始记录和用户消息；每次等代理真实回答再继续，不能由评审代造输出。
- 默认只在聊天中测试。要验证真实文件读写，先声明临时目录、文件范围并取得授权，禁止接触真实学习档案。
- 记录 skill 的提交 SHA、宿主版本、模型实际标识、时间、使用语言和原始对话或脱敏引用。
- 每个检查项分别写 pass、fail 或 not_run，附实际输出；无法观察的行为保持 not_run。
- 静态链接检查或人工重算日期不能替代模型行为验收；这些场景通过也不证明长期学习效果。
