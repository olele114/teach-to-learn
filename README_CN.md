> **拒绝「看懂教材 = 已经学会」的 AI 学习幻觉。**
> 一个面向学习者的中文 Agent Skill：先约定可观察的完成标准，再通过诊断摸底、5–15 分钟微课、开放式真实作答、间隔复习队列与迁移验收任务，帮助你逐步独立完成真实任务。

适合需要分多次逐步掌握编程、语言、课程概念或工作技能的学习场景；单次零散问题可直接向助手提问，无需建立学习目录。

```text
明确可观察目标 ─▶ 短诊断摸底（≤3 题） ─▶ 5–15 分钟微课 ─▶ 开放式作答/纠错 ─▶ 记录证据与 1/3/7/14 天复习队列 ─▶ 新迁移任务达标结课
```

## 相比原版 `teach` 改进了什么

基于 [Matt Pocock 的 `teach`](https://github.com/mattpocock/skills/tree/5863806dd4e15c63174bee4e7515a4256792ecfa/skills/productivity/teach) 重新设计，保留目标驱动、可信来源、小课拆解与跨会话记录，同时针对以下典型痛点做了工程化约束：

| 原版版本的不足或风险 | 本 Skill 的具体调整 |
| --- | --- |
| 首轮仅凭目标和自述推断水平 | 最多出 3 个短诊断任务（一次一题），严格区分「用户自述」与「实际观察」；允许直接跳过 |
| 仅口头提及间隔练习原则 | 内置可协商调整的 **1、3、7、14 天**复习队列，明确失败、跳过与逾期处理规则 |
| 缺乏清晰的结课与退出标准 | 开局约定可观察的完成标准，通过全新迁移任务验收后转入真实实践或结束课程 |
| 选择题选项位置可能泄露答案线索 | 默认采用开放式回忆、结果预测、代码纠错或实际演示；选择题答对不计为独立掌握证据 |
| 读过材料容易被误判为已经学会 | 如实记录真实作答与提示帮助程度；区分「初步独立」与隔天验证后的「延迟巩固」 |
| HTML 互动页的点击结果可能与会话脱节 | 未验证读取能力时要求粘贴结果；未收到结果前保持「待核验」状态 |
| 工具与来源核查能力依赖宿主环境 | 无文件写权限时支持纯聊天续学并输出续学摘要；离线解释明确标出「待核验内容」 |

> **说明：** 以上是针对固定上游版本的教学规范调整，不代表所有底层模型都能稳定执行，也不构成学习效果的实证实验结论。

## 安装到 Codex CLI

需要支持本地 skills 的 Codex CLI 以及用于克隆仓库的 Git；本 Skill 本身**无任何运行时依赖**。

以下命令适用于 macOS、Linux 或 WSL（执行前请确保目标目录尚不存在）：

~~~sh
mkdir -p ~/.agents/skills
git clone https://github.com/olele114/teach-to-learn.git ~/.agents/skills/teach-to-learn
~~~

在 Codex 中输入 `/skills` 确认 `teach-to-learn` 已加载（若未出现，重启会话即可）。
你也可以将整个仓库放入具体项目的 `.agents/skills/teach-to-learn/` 目录下，供团队在该项目内共用。
**请勿只单独复制 `SKILL.md`：** `references/` 目录包含了运行流程必需的状态管理与课程质量规范。

> **注意：** **Skill 安装目录**与**你的学习目录**应当分开。请在自己的学习工作目录下启动 Codex，不要直接在安装目录中开始课程。
> 其他兼容 Agent Skills 规范的宿主亦可导入此目录，具体安装路径与调用方式请参考对应宿主文档。本仓库为独立指令型 Skill，不包含插件、MCP 服务或模型配置。
> 格式与路径规范依据 [Codex skills 文档](https://developers.openai.com/codex/skills/)。

## 第一次使用

请在 **Codex 的聊天输入框**中发送以下内容（而非操作系统终端）：

~~~text
$teach-to-learn
我想学习 Python asyncio，目标是能独立修复一个异步请求程序。
我会基本 Python，但不理解事件循环。每次 15 分钟，用中文讲解。
先只在聊天里学，不创建文件。
~~~

助手会先澄清你的目标，随后**每次只给出一个短诊断任务并等待你的回答**。
直接回答「不知道」、要求跳过或缩短单次时长都可以；跳过的题目会如实记为「未评估」，不会强制补测。

若需要跨会话保存进度，请明确指定目录并授予写入许可：

~~~text
把这个主题保存在 ./learning/python-async/。
先告诉我计划写入哪些文件，按我的编辑审批规则处理。
~~~

助手会先检查目录中是否已有文件并取得写入授权；即使不授予权限，也可以继续在纯聊天中完成学习。
学习记录可能包含你的作答内容与个人偏好，请自行决定保存路径及是否分享；本 Skill 不会自动执行 Git 提交或对外上传。

## 一次学习会怎样进行

~~~text
你：今天只学如何区分等待与阻塞。
助手：说明用途 → 定义必要术语 → 给出一个已讲解例子 → 抛出一个新的开放任务，然后停止并等待回答。
你：提交自己的预测与理由，或粘贴程序实际运行结果。
助手：指出具体正确点与误区；需要时先给出最小提示，不直接剧透答案。
你：重新尝试作答，或说「直接给答案」「今天暂停」。
助手：总结本次观察到的证据、帮助程度、待核验项及下次学习建议。
~~~

以上仅为交互流程示例，并非真实学习日志。生成课程、看过参考答案或回复「明白了」均不会自动计为独立完成。
当前环境无法执行的代码会明确标为「未运行」；HTML 页面的点击或测验分数通常不会自动回传至聊天窗口。

## 续学与常用请求

在同一个学习目录打开新会话，并显式调用技能：

~~~text
$teach-to-learn 继续这个目录的学习。先读已保存状态，今天只复习最相关的两项。
~~~

学习过程中，你也可以随时用自然语言调整节奏：

- 「不要再讲新知识；给我一个不重复上次答案的迁移任务。」
- 「这一步跨度太大，先检查我缺哪个先修概念。」
- 「我需要一点提示，请记录提示使用情况，不要把这次算成独立完成。」
- 「不要生成 HTML，全部用纯文本；每课控制在五分钟以内。」
- 「修改学习目标前先和我确认；这周不安排额外练习。」

若未使用本地文件保存进度，只需将上一轮结束时生成的**续学摘要**贴给助手即可继续；若无摘要，助手会通过一个短诊断重新定位起点，绝不假装记得历史对话。

## 文件结构

核心入口包括 `SKILL.md`、`README.md`、`README_CN.md`、`LICENSE`、`ATTRIBUTION.md` 和 `references/` 下的规范。
另提供[人工构造的学习目录](examples/python-await/README.md)和[手工验收场景](evals/scenarios.md)，保持零运行时依赖。
实际学习目录仅在你授权后按需生成，安装时不会自动创建：

~~~text
learning/python-async/
├── MISSION.md                  # 学习目标、可观察完成标准与个人偏好
├── RESOURCES.md                # 参考来源、对应章节、适用版本及核验状态
├── STATE.md                    # 能力证据记录、帮助程度与下一步计划
├── REVIEW.md                   # 下次学习时优先读取的间隔复习队列
├── learning-records/0001-*.md  # 真实作答摘要（不保存标准答案）
├── lessons/0001-*.md           # 微课内容（按需改用 HTML）
└── reference/                  # 术语表与速查笔记
~~~

各文件详细字段定义见[状态与复习规范](references/state-and-review.md)，教学与评估标准见[课程质量约定](references/lesson-quality.md)。

## 如何理解进度与复习

- **固定状态 ID：** 存储 `unassessed`、`scaffolded`、`provisional`、`consolidated`；中文依次显示为未评估、需支架、初步独立、延迟巩固。换语言不另建知识点，旧中文和英文状态名继续可读。
- **状态变化：** 可评估的错误或依赖提示会让该知识点回到需支架，保留历史证据；恢复后的首次新题独立成功只回到初步独立。巩固要求另一会话且距最近独立成功满 **24 小时**。
- **复习节奏：** 首次或恢复成功后 +24 小时、次数为 0；只有合格的到期复习才推进次数，并建议 +72、+168、+336 小时。提前练习和重复事件不推进次数。
- **排期选择：** 记录带时区的时间；时间不可靠时用相对的下次学习建议。跳过只延后本会话，不算失败；用户可修改或拒绝安排。
- **续学兼容：** 不自动迁移旧记录，缺失字段先核对。没有后台提醒或自动评分，目标达标后由用户选择实践、维护复习或结束。

## 案例、验收与兼容性

[Python await 人工案例](examples/python-await/README.md)包含小课、两次会话记录及对应的状态和复习文件。数据完全构造，已展示答案，不是真实用户记录或学习效果证据。

当前仓库尚未记录真实模型行为或跨宿主验收结果；其他兼容宿主在实测前标为未验证。

## 限制与来源

- 本项目是供 AI Agent 执行的教学工作流规范，不包含自动评分器或效果保证；发布前的文档自检也不等同于真实学习者对照实验。
- 涉及关键知识来源与系统操作步骤时请务必自行核对；本规范严格区分「未核验内容」「用户自述」与「直接观察证据」。
- **更新方法：** 更新前请先检查是否有本地修改；若无改动，可在安装目录执行 `git pull --ff-only`，随后重新检查 `/skills`。
- **卸载方法：** 仅移除你确认的 Skill 安装目录即可；个人学习目录独立保留，切勿混删。
