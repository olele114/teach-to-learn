# 状态与复习规范

所有路径相对于用户批准的学习目录，不相对于 skill 安装位置。
记录采用可读 Markdown；这是代理维护的约定，不是自动执行的学习管理系统。

## 按需生成的文件

| 路径 | 内容 |
| --- | --- |
| MISSION.md | 真实目标、完成标准、先修条件、时间预算、教学偏好 |
| RESOURCES.md | 来源 ID、标题、链接或本地路径、章节、版本、核验状态与时间 |
| STATE.md | 当前能力证据、帮助程度、误区及下一步；不存标准答案或完整题库 |
| REVIEW.md | 待复习概念、证据引用、建议时间、排期理由和连续独立复习次数 |
| learning-records/0001-topic.md | 追加式会话记录，编号只递增，不覆盖旧记录 |
| lessons/0001-topic.md | 一次一个小课；用户需要时可另用 HTML |
| reference/glossary.md | 已引入术语的统一定义，按需维护 |
| reference/topic.md | 一页速查，连接课程和来源，不充当掌握证据 |

## 最小状态模板

MISSION.md：

- 主题与真实用途：
- 可观察的完成标准：
- 已自述的经验与尚未核验的先修条件：
- 每次时间预算、语言与教学偏好：
- 经用户确认的目标变更：

STATE.md：

| 能力 | 状态 | 证据及来源 | 帮助程度 | 下一步 |
| --- | --- | --- | --- | --- |
| 待诊断的能力 | 未评估 | 无 | 未知 | 一个简短诊断任务 |

能力状态仅用“未评估、需支架、初步独立、延迟巩固”。
“需支架”表示仍需提示；“初步独立”须有未见过任务的独立表现。
“延迟巩固”须在之后会话、至少隔一天的新任务上独立完成；无法确定时间时不升级。
用户自述的结果标注“自述，未独立核验”，不能冒充代理直接观察的证据。
诊断正确也可作为能力证据；同样适用新任务、帮助程度和延迟要求。
会话记录至少写：真实日期或“未知”、本次目标、作答摘要、提示、反馈、状态变化及理由。
不保留不必要的个人信息；不把答题答案写入续学状态，避免下次测验被答案污染。

## 可解释的默认排期

这是便于执行、可由用户调整的启发式规则，不是记忆保持效果的保证。
有可信当前日期时使用该日期，说明采用的时区；无时区偏好时明确使用 UTC。
没有可靠日期时使用“下次学习、再隔一次学习”等相对顺序，不伪造精确日期。

- 第一次在新任务上独立完成：复习次数为 0，建议一天后复习。
- 独立通过第一次、第二次、第三次及之后的复习：次数加一，分别建议三、七、十四天后复习。
- 时间都从实际本次作答日期起算，不从原定到期日起算。
- 回答错误或需要提示：次数重置为 0，优先补缺，安排下次学习复查；不抹除历史证据。
- 跳过：不增加次数、不伪造成功，和用户协商下一次安排。
- 逾期：不清零；优先处理阻塞目标的误区，再选到期项，每次默认最多两项。
- 目标迁移任务达标后询问是否保留维护性复习，不无限强制新增课程。

没有后台提醒、日历或自动评分。队列只在用户再次学习时由代理读取和更新。
